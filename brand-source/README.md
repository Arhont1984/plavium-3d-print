## Как получить чистую вырезку логотипа с прозрачностью

Готового alpha-PNG нет ни в одном файле, его нужно собирать самостоятельно. Проверенный
рабочий способ (использовался в одной из версий главной страницы, сейчас не активен —
см. «История экспериментов» в [CLAUDE.md](../CLAUDE.md)):

1. Взять `no_fon/nofon (3).png` (чёрный фон — единственный вариант, где яркость надёжно
   отделяет золото от фона по всему изображению, включая замкнутые "дырки" в буквах
   А/В/О — на шахматном фоне (1)/(2) так сделать нельзя: тень и шахматка неотличимы от
   фона по цвету, получится шум).
2. Прочитать сырые пиксели (`sharp(...).raw().toBuffer()`), для каждого пикселя посчитать
   яркость `0.299r + 0.587g + 0.114b` и сделать альфу через smoothstep между порогами
   ~35 (полностью прозрачно) и ~75 (полностью непрозрачно) — калибровалось по гистограмме
   яркости конкретно этого рендера, при других исходниках пороги пересчитать заново.
3. `.trim()` — обрезать по альфе до тесного бокса вокруг букв.
4. Если нужна тень (в (2) она есть, но её нельзя корректно вытащить с шахматного фона) —
   рисовать её синтетически: чёрный силуэт по альфе букв → `blur()` → уменьшить альфу до
   ~50% → сместить вниз-вправо → скомпоновать ПОД буквами. Рабочий код такого пайплайна
   сохранён в истории git (коммит с сообщением «Добавить мягкую тень под логотипом»),
   можно поднять через `git show <hash>:scripts/optimize-brand-images.mjs`.
5. **Грабля, на которую уже наступали:** `sharp(...).extractChannel(n).toBuffer()` без
   `.raw()` отдаёт PNG-байты, а не сырые пиксели — если читать их как raw-буфер, получится
   мусор (в данном случае — горизонтальная полоса через всё изображение). Всегда добавлять
   `.raw()` перед `.toBuffer()`, когда нужны именно пиксельные значения.
